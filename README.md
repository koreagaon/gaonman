## 미리보기

압축을 풀고 `index.html`을 브라우저로 열면 디자인과 언어 전환을 볼 수 있습니다. 안정적인 미리보기와 상담 인터페이스 사용에는 Python 3으로 아래 명령을 실행하세요.

```text
python server.py
```

그런 다음 http://localhost:8765/ 를 엽니다. 이 주소는 이 컴퓨터에서만 작동합니다.

HTML 파일과 assets 폴더는 일반 정적 웹 호스팅에 올릴 수 있습니다. 독립 도메인과 호스팅은 아직 연결하지 않았습니다. 새 도메인을 연결할 때 canonical, Open Graph URL 등을 새 주소로 설정할 수 있습니다.

## 상담 이메일 연결

기본 수신 이메일은 **asianwave@naver.com**으로 설정했습니다. 서버의 CONTACT_TO 환경변수로 변경할 수 있습니다. 수신 주소 설정만으로 발송이 활성화되지는 않습니다.

원본 SITE123의 비공개 수신함은 복제할 수 없습니다. 현재 SMTP가 설정되지 않아 문의가 전송되지 않으며, 화면에는 KakaoTalk 문의 안내가 표시됩니다. 전송 성공으로 표시하지 않습니다.

제공된 `server.py`는 개발·미리보기용 서버와 이메일 연결 예제입니다. 운영 배포에서는 HTTPS 프록시, 프로세스 관리 및 서비스에 맞는 스팸 방어를 구성하세요. 다음 값을 서버 환경변수로 설정해야 이메일이 실제 발송됩니다.

- SMTP_HOST / SMTP_PORT (기본 587, STARTTLS)
- SMTP_FROM (발신 주소) / CONTACT_TO (선택 사항, 기본값 asianwave@naver.com)
- SMTP_USER / SMTP_PASSWORD (메일 서비스에서 인증을 요구할 때)
- PORT (기본 8765), HOST (기본 127.0.0.1)

비밀번호는 HTML 또는 공개 파일에 넣지 마세요. 정적 호스팅만 이용할 경우 해당 호스팅의 폼 서비스나 별도 백엔드에 `assets/contact.js`를 연결해야 합니다.
